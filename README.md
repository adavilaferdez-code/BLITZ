# BLIZT Pro - Cartera de Clientes & Cajas

Aplicación web progresiva (PWA) para gestión comercial de clientes, seguimiento de cajas y semáforos de riesgo para preventistas.

## 🚀 Archivos Principales de la Aplicación

- **`index.html`**: Aplicación web completa con interfaz interactiva, filtros, cartera de clientes y buscador.
- **`manifest.json`**: Configuración PWA para instalación en dispositivos móviles y escritorio.
- **`sw.js`**: Service Worker para soporte sin conexión (offline) y caché network-first.
- **`logo_antonio.png`**: Icono de la aplicación.
- **`xlsx.full.min.js`**: Biblioteca para importación y exportación de datos en formato Excel.

## 🛠️ Herramientas de Datos (Opcional)

- **`blizt_data.json`**: Base de datos de clientes y métricas en formato JSON.
- **`build_blizt_pro.py`**: Script en Python para recompilar e inyectar datos en `index.html`.
